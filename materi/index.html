Stimulasi

Perhatikan dua kode PHP ini. Apa perbedaannya?

Keduanya mengurus saldo akun Budi dan Sari. Tanda … menyembunyikan sebagian isi kode.

Kode 1

$pemilikBudi = "Budi";
$saldoBudi = 50000;
$pemilikSari = "Sari";
$saldoSari = 10000;
function setor($saldo, $jumlah) { … }
function lihatSaldo($pemilik, $saldo) { … }
$saldoBudi = setor($saldoBudi, 20000);
lihatSaldo($pemilikBudi, $saldoBudi);
lihatSaldo($pemilikSari, $saldoSari);

Kode 2

class Akun {
public $pemilik;
public $saldo;
public function setor($jumlah) { … }
public function lihatSaldo() { … }
}
$akunBudi = new Akun();
$akunBudi->setor(20000);
$akunBudi->lihatSaldo();
$akunSari = new Akun();
$akunSari->lihatSaldo();
Awal · Stimulasi · menit 8–123 / 15
Tampilkan kedua kode berdampingan dan beri waktu membaca. Tanyakan: “Apa perbedaan kedua kode ini?” Beri 10 detik berpikir, lalu ambil dua sampai tiga jawaban. Jawaban yang diharapkan (dengan kata murid): kode 2 memakai class dan new; data dan fungsi pada kode 2 dikumpulkan di satu tempat; kode 1 memakai banyak variabel terpisah. Jangan menyebut istilah dan jangan membahas hasilnya; murid akan menemukannya sendiri. Jawaban yang kurang tepat dicatat dan dibahas di akhir.

Pernyataan Masalah

Kenali isi kode ini

Kode ini menyimpan saldo dua akun bank. Perhatikan bagian-bagiannya.

class Akun {
public $pemilik;
public $saldo;
public function setor($jumlah) {
$this->saldo = $this->saldo + $jumlah;
}
public function lihatSaldo() {
echo $this->pemilik . " memiliki saldo Rp " . $this->saldo . "<br>";
}
}
$akunBudi = new Akun();
$akunBudi->pemilik = "Budi";
$akunBudi->saldo = 50000;
$akunBudi->setor(20000);
$akunBudi->lihatSaldo();
$akunSari = new Akun();
$akunSari->pemilik = "Sari";
$akunSari->saldo = 10000;
$akunSari->lihatSaldo();

Menarik Kesimpulan

Ini nama resmi temuan kalian

Class

Cetakan untuk membuat objek, seperti cetakan kue.

Misalnya Akun dan Buku

Atribut

Data milik objek.

Misalnya pemilik, saldo, dan judul

Method

Aksi yang bisa dilakukan objek.

Misalnya setor() dan pinjam()

Objek

Hasil cetakan class, dibuat dengan new.

Misalnya $akunBudi dan $akunSari

Merefleksi · Menarik Kesimpulan · menit 72–7412 / 15
Cocokkan kalimat murid dengan istilah resmi satu per satu: cetakan adalah class, data adalah atribut, aksi adalah method, hasil cetakan adalah objek. Jelaskan singkat bahwa beberapa objek dari satu class berdiri sendiri. Istilah bahasa Inggris: class, attribute (atau property), method, object.

Penutup

Rangkuman pertemuan hari ini

  1. PBO menyusun program dari objek yang punya data dan aksi.
  2. Class adalah cetakan; objek adalah hasil cetakan yang dibuat dengan new.
  3. Atribut menyimpan data objek; method menjalankan aksi objek.
  4. Setiap objek dari satu class berdiri sendiri.
Minggu depan kita belajar melindungi data di dalam objek.
